# Lease Not Yet Commenced Reported as an Unrecorded Unconditional Purchase Obligation
Rule ID: DQC.US.0251  
Status: Proposed  
Public Review Release date: TBD  
Effective date: TBD

## Rule Function

**Purpose:**

The purpose of Rule DQC.US.0251 is to ensure that the amount of a lease that has not yet commenced is reported using `UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount` (and the related maturity elements) with the correct axis and member. The US GAAP taxonomy models leases that have not yet commenced using the `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` with the members `OperatingLeaseLeaseNotYetCommencedMember` and `FinancingLeaseLeaseNotYetCommencedMember`.

**Conditions:**

The rule evaluates facts reported with the following unrecorded unconditional purchase obligation (UUPO) elements:

- `UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount`
- `UnrecordedUnconditionalPurchaseObligationBalanceOnFirstAnniversary` through `UnrecordedUnconditionalPurchaseObligationBalanceOnFifthAnniversary`
- `UnrecordedUnconditionalPurchaseObligationDueAfterFiveYears`
- `UnrecordedUnconditionalPurchaseObligationDueInRemainderOfFiscalYear`
- `UnrecordedUnconditionalPurchaseObligationDueInNextRollingTwelveMonths` and `UnrecordedUnconditionalPurchaseObligationDueInRollingYearTwo` through `UnrecordedUnconditionalPurchaseObligationDueInRollingYearFive`
- `UnrecordedUnconditionalPurchaseObligationDueInRollingAfterYearFive`
- `UnrecordedUnconditionalPurchaseObligationChangeOfAmountAsResultOfVariableComponents`
- `UnrecordedUnconditionalPurchaseObligationPurchases`
- `UnrecordedUnconditionalPurchaseObligationImputedInterest`

The lease-not-yet-commenced members accepted on `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` are the standard members `OperatingLeaseLeaseNotYetCommencedMember` and `FinancingLeaseLeaseNotYetCommencedMember`, and the extension member `OperatingAndFinancingLeaseLeaseNotYetCommencedMember` (in the filer's namespace) when operating and finance leases are combined into a single total.

Assertion 10964 fires when a UUPO element is reported with a lease member (a member whose name contains "Lease", excluding leasehold members) on any axis other than `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis`.

Assertion 10965 fires when a UUPO element is reported on `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` with an extension member representing a lease other than the accepted members listed above.

Assertion 10966 fires when an element other than the UUPO elements is reported with one of the accepted lease-not-yet-commenced members on `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis`, and no UUPO element is reported with the same member, period and dimensions.

## Problem Solved by the Rule

The element `UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount` is defined as the "amount of unrecorded obligation to transfer funds in future for fixed or minimum amount or quantity of product and service at fixed or minimum price. Includes, but is not limited to, lease not yet commenced and take-or-pay and throughput contracts." In the 2026 taxonomy the lease disclosure (`Leases842UnrecordedUnconditionalPurchaseObligationTable`) uses this element with `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` to distinguish operating leases and finance leases not yet commenced.

Filers have been identifying leases not yet commenced by placing lease members on other axes (such as `LeaseContractualTermAxis` or extension axes), by creating extension members, or by using the lease-not-yet-commenced members with lease liability elements. These inconsistencies make it impossible for users to reliably extract the amount of leases that have not yet commenced.

## Example Rule Message

**10964:** The filer has reported a value of 25,000,000 for the concept UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount with the following lease related axis and member combination(s): ProductOrServiceAxis = OperatingLeaseNotCommencedMember. When an unrecorded unconditional purchase obligation represents a lease that has not yet commenced the lease should be identified using the axis UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis with the member OperatingLeaseLeaseNotYetCommencedMember or FinancingLeaseLeaseNotYetCommencedMember or an extension of OperatingAndFinancingLeaseLeaseNotYetCommencedMember. Please update the dimensional qualification of this fact to use the UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis.

**10965:** The filer has reported a value of 25,000,000 for the concept UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount using the extension member abc:LeasesNotYetCommencedMember on the axis UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis. The US GAAP taxonomy includes the members OperatingLeaseLeaseNotYetCommencedMember and FinancingLeaseLeaseNotYetCommencedMember to represent leases that have not yet commenced. If these are combined into a single total the extension member OperatingAndFinancingLeaseLeaseNotYetCommencedMember should be used. The extension member abc:LeasesNotYetCommencedMember should be replaced with the appropriate standard or extension member.

**10966:** The filer has reported a value of 25,000,000 for the concept OperatingLeaseLiability with the member OperatingLeaseLeaseNotYetCommencedMember on the axis UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis. The filer has not reported a value for UnrecordedUnconditionalPurchaseObligationBalanceSheetAmount for this lease. ... The concept OperatingLeaseLiability should not be used with this axis and member.

Rule Element Id: 10964  
Rule version: 32.0.0RC1

## Rule element ID index  
The rule element ID is used to identify unique elements or combinations of elements tested in the rule.

|Rule Element ID|Element|
|--- |--- |
| DQC.US.0251.10964 | UUPO elements reported with a lease member on an axis other than `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` |
| DQC.US.0251.10965 | Extension lease member, other than `OperatingAndFinancingLeaseLeaseNotYetCommencedMember`, used on `UnrecordedUnconditionalPurchaseObligationByCategoryOfItemPurchasedAxis` |
| DQC.US.0251.10966 | Lease-not-yet-commenced members used with non-UUPO elements when no UUPO element is reported for the lease |

## Technical Details

- A lease member is identified as any member whose local name contains `lease` (case insensitive) and does not contain `leasehold`. Leasehold improvement members on `PropertyPlantAndEquipmentByTypeAxis` are a legitimate property type breakdown and are excluded.
- Assertion 10965 uses the `is_extension` function against `$ALL_BASE_TAXONOMIES_ELTS` to determine if the member is an extension.
- The accepted lease-not-yet-commenced members are defined in the constant `$UUPO_LEASE_MEMBERS`. The combined extension member is matched in the filer's extension namespace (`$EXTENSION_NS`).
- Assertion 10966 evaluates all facts reported with the accepted members, not only numeric facts. It does not fire when the filer also reports a UUPO element with the same member, period and dimensions.

The rule exists in the 2024, 2025, and 2026 US GAAP taxonomy versions.
